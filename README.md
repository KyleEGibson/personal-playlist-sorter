# Personal Playlist Sorter

A small personal tool that reorders Spotify playlists by my own song ratings while keeping
BPM and musical key transitions smooth (DJ-style harmonic mixing).

## Data sources

- Playlist data: [Spotify Web API](https://developer.spotify.com/documentation/web-api)
- BPM and key data: [GetSongBPM](https://getsongbpm.com) — BPM data provided by GetSongBPM.
